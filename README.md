# OpenAI Realtime Console with Firecrawl
Interactive inspector for OpenAI Realtime API with [Firecrawl](https://firecrawl.dev) integration, featuring [openai-realtime-api-beta](https://github.com/openai/openai-realtime-api-beta) reference client and browser audio tools. Run `npm i && npm start` to launch on localhost:3000.
