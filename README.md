# OpenAI Realtime Console with Firecrawl

This project provides an inspector and interactive API reference for the OpenAI Realtime API, enhanced with [Firecrawl](https://firecrawl.dev) integration. The console allows developers to explore and test the capabilities of OpenAI's real-time voice and audio API in an intuitive web interface. With Firecrawl integration, you can seamlessly incorporate web scraping and content extraction capabilities into your real-time AI applications.

Getting started is simple: install dependencies with `npm i`, start the development server with `npm start`, and access the console at `localhost:3000`. The interactive console provides a hands-on environment for experimenting with real-time AI interactions, making it easier to understand the API's features and build your own applications.
